ACERCA DEL BLOG

Un cuaderno abierto
al aprendizaje.

Aula en perspectiva reúne tres propuestas sencillas para pensar la enseñanza en educación primaria. Su propósito es ofrecer actividades y preguntas que puedan adaptarse a diferentes ritmos de aprendizaje.

Quién escribe

Alexander Reyes, docente de primaria. Este blog se presenta como un proyecto académico para aplicar los fundamentos de HTML y CSS a un sitio web estático.

Cómo está construido

Las páginas utilizan HTML semántico y una hoja de estilos CSS compartida. Un pequeño generador en Python combina una plantilla con el contenido de las entradas y produce los archivos HTML. El sitio publicado no necesita Python, bases de datos ni JavaScript.

Las ilustraciones SVG son originales y están almacenadas con el sitio. El diseño se adapta a móviles y computadores mediante CSS Grid y consultas de medios.

Cómo recorrerlo

Desde Inicio puedes acceder a las tres entradas. Cada artículo permite volver al índice o continuar con la siguiente lectura. El menú principal está disponible en todas las páginas.

Los textos son propuestas didácticas de carácter ilustrativo. No presentan resultados de una intervención ni datos de estudiantes.
